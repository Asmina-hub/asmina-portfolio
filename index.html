03 — Projects

Selected work

Featured Master's thesis · OVGU Magdeburg

Robot localization on evacuation plans with MCL and LLM observations

Estimating a robot's position and heading on a building evacuation plan, with no SLAM map. A particle filter fuses odometry, LiDAR and camera detections with an LLM that reads the plan and the scene, then reports which room the robot is in and which way it faces.

  • Monte Carlo localization with an odometry motion model, a furniture-robust LiDAR likelihood, and low-variance resampling with random injection to recover from wrong pose locks.
  • LLM as a probabilistic sensor: plan, camera image, LiDAR summary and detections in; structured room and heading probabilities out, fused as a softened likelihood.
  • Prompt-free YOLOE detector with a depth camera and a 360° look-around that groups objects by direction.
  • OpenCV pipeline that turns evacuation-plan images into navigable maps with walls, free space and a distance field.

Autonomous exploration & room recognition

A ROS 2 robot that maps an unknown multi-room house live, decides where to explore next, and works out what each room is from the objects it sees.

  • Custom frontier detection on the SLAM Toolbox occupancy grid; Nav2 for navigation.
  • py_trees behaviour tree with a shared blackboard for mapping, perception and exploration.
  • YOLOE + depth projected into world coordinates and clustered into a scene graph; an LLM (Claude API) infers the room type and re-queries until confident.

AI & LLMs Personal project

Self-correcting Text-to-SQL agent

A LangGraph agent that lets non-technical users query a database in plain language, and fixes its own SQL when a query fails.

  • Self-healing ReAct loop feeds execution errors (syntax, schema mismatch) back to the LLM to regenerate the query.
  • Schema-aware graph state (Pydantic) retrieves only the relevant table metadata.
  • Human-in-the-loop approval before any INSERT / UPDATE / DELETE; charts generated in the same flow.
